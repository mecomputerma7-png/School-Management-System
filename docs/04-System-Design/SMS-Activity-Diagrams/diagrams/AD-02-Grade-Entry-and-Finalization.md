# Grade Entry and Finalization (UC-07 / UC-08)

**Diagram ID:** 02  
**Scope:** School Management System (Desktop-only, one school).

## Process activities

- Teacher opens assigned assessment
- Access denied
- Display read-only grades
- Enter grades for enrolled students
- Correct invalid scores
- Save draft grades transactionally
- Rollback; display error
- Authorized reviewer examines grades
- Return for correction
- Finalize grades; lock approved results
