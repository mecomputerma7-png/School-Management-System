# Report Generation (UC-13)

**Diagram ID:** 04  
**Scope:** School Management System (Desktop-only, one school).

## Process activities

- User opens Reports Center
- Display access denied
- Select report and filter criteria
- Show filter errors
- Query authorized records from central database
- Display retrieval error
- Show empty-state message
- Format and preview report
- Export or print report
