# Payment Registration (UC-10)

**Diagram ID:** 03  
**Scope:** School Management System (Desktop-only, one school).

## Process activities

- Accountant opens student charges
- Access denied
- Select unpaid charges and enter amount
- Correct amount / allocations
- Reject overpayment
- Begin transaction; create payment and allocations
- Rollback; show failure
- Commit; issue receipt and audit entry
