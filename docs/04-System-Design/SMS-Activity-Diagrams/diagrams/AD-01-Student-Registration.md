# Student Registration (UC-02)

**Diagram ID:** 01  
**Scope:** School Management System (Desktop-only, one school).

## Process activities

- Administrative staff opens registration form
- Show access denied
- Enter student information
- Display validation errors
- Show duplicate warning
- Begin transaction; insert Student record
- Rollback; show error
- Commit; show student record
